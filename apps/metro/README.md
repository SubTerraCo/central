# Metro

Dewey `MT`. Public PWA for social and ticketing. `pnpm dev:web` serves it at http://localhost:1421.

This slice is a social entry scaffold: an in-memory feed and profile on Home / Profile. There is no social backend, auth, or live bridge here. Marketplace and installed packages still run through the shell.

The owner-marked bridge allowlist is OB + OL + OT + AT. It stays off until the owner turns it on.
